Pips Master Academy — targeted update

Only these areas were changed:
1. Day Trade Monitor: cache-first switching, faster market/timeframe transitions, lighter background prefetching, and no duplicate live request on initial load.
2. Trading History: faster parallel loading, client-side market/outcome filters, refresh control, and fuller trade details (entry/SL/TP/reason).
3. Email verification: new-account verification tokens, resend flow, verification endpoint/page, login enforcement, and profile verification status.

Email delivery environment variables for the backend:
PMA_SMTP_HOST
PMA_SMTP_PORT (default 587)
PMA_SMTP_USERNAME
PMA_SMTP_PASSWORD
PMA_EMAIL_FROM (optional; defaults to SMTP username or admin email)
PMA_SMTP_USE_TLS (default 1)
PMA_VERIFY_BASE_URL (optional; defaults to the deployed API base)

Existing accounts are treated as already verified during database migration so current users are not locked out. New non-admin accounts must verify their email before login.
