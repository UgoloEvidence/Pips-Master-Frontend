- Voice notes are available to all Community members through the browser microphone and are stored as message audio.
- Voice/video call controls are visible only to the administrator. Actual live WebRTC signalling is still a separate production service requirement.
- Telegram/customer-care contact was removed from About Us and the Q&A answer.
- Q&A remains an expandable accordion.
- TradingView theme iframe receives a cache-busting reload when switching theme so light/dark follows the website.
- Pull-to-refresh gesture is enabled on the main app scroll area; no page-refresh button is required for that gesture.
- My Progress includes the full academic rank ladder, maximum Pips Master rank, progress path and learning badges.
- Admin progress is displayed at the maximum Pips Master rank.
- Login/authentication code was not changed in this update.
- Existing account token, profile picture, community messages and server-side account data are not intentionally cleared by this update.

Production persistence note:
- Render SQLite remains subject to Render filesystem persistence limitations. True long-term cross-device persistence requires supported persistent storage/PostgreSQL.
