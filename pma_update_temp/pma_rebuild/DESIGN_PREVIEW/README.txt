PIPS MASTER ACADEMY — UI PREVIEW

This preview shows the rebuilt member and administrator experience, including:
- Member login/dashboard
- Community with permanent messages
- 24-hour temporary-message mode with visible countdown
- Member profile -> message request -> accepted private chat
- Members cannot message/request the administrator
- Administrator can start private chats with members without a request
- Message reactions, views, editing and deleted-message markers
- Admin community controls and member moderation
- Responsive/mobile layout

The scanner is designed around confirmation and freshness, not random or visually extreme chart patterns. It should not treat every wedge, FVG, liquidity sweep or other pattern as an automatic trade.
